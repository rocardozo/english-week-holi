# Holi Festival App Rules

## Architecture
- Maintain separate HTML files for each page (`index.html`, `menu.html`, `colors.html`, `trivia.html`, `mural.html`).
- Keep styles in `css/style.css` and scripts in `js/`.
- Maintain native links and back-navigation buttons.

## Bilingual Support (English 🇬🇧 & Spanish 🇪🇸)
- All pages, games, trivia questions, cards, and UI elements must support both English and Spanish.
- Default to English, with instant toggle button in header/navbar.
- Live switching without page reload or state reset during games.
- Store selected language in `localStorage`.

## UI & Aesthetics
- Vibrant, festive, colorful Holi festival theme.
- Glassmorphism, animations, floating particles canvas.
- Mobile-first responsive design for QR code visitors.

## Language Level (English File Elementary - 1st & 2nd Year)
- Syllabus: A1/A2 English File Elementary Book.
- Allowed Grammar: Present Simple & Continuous, Past Simple (regular & common irregulars), Past Continuous, `can/can't`, `like/love + -ing`, routines, comparative/superlative adjectives.
- Keep English clear, simple, and friendly for 1st/2nd year students.
